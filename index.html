WebRTC · collegamento diretto

Due moto.
Nessun server di gioco.

L’host può partire subito con i bot e aggiungere rider mentre gioca. Ogni nuovo browser riceve un link diretto dedicato: la partita non passa da un server di gioco.

01 / INVITO

Avvia l’arena e crea un link per il prossimo posto libero. Ripeti per ogni nuovo rider.

02 / RISPOSTA

Il rider ti rimanderà un link risposta: incollalo nella scheda originale dell’host.

01 / INVITO

Aprendo il link il campo si compila da solo; altrimenti incollalo qui.

02 / RISPOSTA

Rimanda il link all’host. Entrerai appena lo incollerà nella sua scheda originale.

Pronto.

Un link pubblico riutilizzabile, una lobby aperta o l’ingresso automatico richiederebbero almeno un server di segnalazione. Qui ogni invito è monouso e P2P. Un servizio STUN pubblico aiuta i browser a trovarsi; reti molto restrittive possono comunque bloccare il collegamento.
